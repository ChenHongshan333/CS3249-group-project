# Workflow photos

`scripts/run_workflow.py` skips a photo check until its picture is here. Take them from roughly where the glasses would be (eye level, looking down at the counter), as JPEGs:

| File | What it shows |
| --- | --- |
| `chicken_surface.jpg` | The chicken in the pan, turned over, golden with one darker patch |
| `chicken_centre_dark.jpg` | The chicken cut open at the thickest part, in poor light |
| `chicken_centre_bright.jpg` | The same cut, in good light |
| `plated.jpg` | The chicken next to pasta coated in sauce |

Photos of people's faces or homes shouldn't be committed. Crop to the counter.
